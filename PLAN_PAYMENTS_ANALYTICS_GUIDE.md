Project identifier**Query Parameters:**- `days` (integer, optional) - Days to look back (default: 30, range: 1-365)**Headers:**- `Authorization: Bearer <token>` - Authentication required### **Response Model: `List[TimeSeriesData]`**`pythonclass TimeSeriesData(BaseModel):    date: str       # YYYY-MM-DD format    value: int      # Revenue in cents`### **Response Example**`json[  { "date": "2025-10-06", "value": 0 },  { "date": "2025-10-07", "value": 2999 },  { "date": "2025-10-08", "value": 0 },  { "date": "2025-10-09", "value": 5998 },  { "date": "2025-10-10", "value": 2999 },  { "date": "2025-11-05", "value": 8997 }]`**Note:** Values are in cents. Dates with no revenue show `value: 0`.---## 📤 Endpoint 4: Export Analytics### **GET** `/analytics/{project_id}/export`Export comprehensive analytics data.### **Request\***\*Path Parameters:**- `project_id` (string, required) - Project identifier**Query Parameters:**- `format` (string, optional) - Export format: `json` or `csv` (default: json)- `days` (integer, optional) - Timeseries data range (default: 30, range: 1-365)**Headers:**- `Authorization: Bearer <token>` - Authentication required### **Response\*\***Content-Type:**- `application/json` (when format=json)- `text/csv` (when format=csv)**Headers:**- `Content-Disposition: attachment; filename="analytics_{project_id}.{format}"`### **Exported Data Includes:**- ✅ Overview stats (collections, documents, users, functions)- ✅ Collection analytics- ✅ User analytics- ✅ API usage- ✅ Cloud function analytics- ✅ Plan limits and usage- ✅ Payment analytics- ✅ Timeseries data (documents, users, revenue)### **JSON Response
