We're excited to announce Schema Migrations, a powerful new feature that lets you safely transform your database structure without downtime.

What Can You Do?
Manage your collections with ease using 6 core operations:

Rename Fields - Change field names across all documents
Add Fields - Introduce new fields with default values
Delete Fields - Remove fields safely (with confirmation)
Convert Field Types - Transform data between types (string → number, etc.)
Merge Fields - Combine multiple fields into one
Split Fields - Break one field into multiple fields
Key Features
✨ Intuitive Step-by-Step Flow - Select collection → View stats → Choose operation → Execute
📊 Real-Time Analytics - See document counts, field analysis, and data coverage before making changes
🛡️ Safe Execution - Confirmation dialogs and warnings for destructive operations
⚡ Instant Results - See exactly how many documents are affected
📱 Works Everywhere - Fully responsive design for desktop and mobile

Get Started
Navigate to any project, click "Migrations" in the sidebar, and follow the intuitive wizard.
